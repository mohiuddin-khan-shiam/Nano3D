# Violence Detection Datasets Collection

This repository provides access to several widely used benchmark datasets for violence, anomaly, and crime detection in surveillance videos. These datasets are commonly utilized in computer vision, video understanding, action recognition, anomaly detection, and deep learning research.

## Available Datasets

| Dataset | Description | Link |
|----------|-------------|------|
| UCF-Crime | Large-scale anomaly detection dataset containing 13 real-world anomalous events collected from surveillance videos. | https://www.kaggle.com/datasets/smmohiuddinkhanshiam/ucf-crime |
| XD-Violence | Large-scale violence detection dataset featuring multimodal surveillance videos with audio and visual information. | https://www.kaggle.com/datasets/smmohiuddinkhanshiam/xd-violence |
| RWF-2000 | Real-world violence detection dataset containing 2,000 surveillance video clips categorized into violent and non-violent classes. | https://www.kaggle.com/datasets/smmohiuddinkhanshiam/rwf-2000 |
| UBI-FIGHTS | Dataset focused on fight detection in surveillance environments, containing fight and non-fight video clips. | https://www.kaggle.com/datasets/smmohiuddinkhanshiam/ubi-fights |
| SCVD Dataset | Surveillance Camera Violence Detection dataset designed for violence recognition and public safety research. | https://www.kaggle.com/datasets/smmohiuddinkhanshiam/scvd-dataset |
| VAD_Binary | Binary Violence Anomaly Detection dataset developed by our research team for violence classification tasks. | https://www.kaggle.com/datasets/smmohiuddinkhanshiam/vad-binary |

---

## Dataset Details

### 1. UCF-Crime

**Description:**  
UCF-Crime is one of the most widely used datasets for anomaly detection in surveillance videos. It contains long untrimmed real-world surveillance videos covering various abnormal events.

**Kaggle Link:**  
https://www.kaggle.com/datasets/smmohiuddinkhanshiam/ucf-crime

---

### 2. XD-Violence

**Description:**  
XD-Violence is a large-scale benchmark dataset for violence detection and anomaly recognition. It contains both visual and audio streams, making it suitable for multimodal learning approaches.

**Kaggle Link:**  
https://www.kaggle.com/datasets/smmohiuddinkhanshiam/xd-violence

---

### 3. RWF-2000

**Description:**  
RWF-2000 is a real-world surveillance violence detection dataset consisting of 2,000 video clips equally distributed between violent and non-violent categories.

**Kaggle Link:**  
https://www.kaggle.com/datasets/smmohiuddinkhanshiam/rwf-2000

---

### 4. UBI-FIGHTS

**Description:**  
UBI-FIGHTS is designed for automated fight detection in surveillance videos and is commonly used for binary violence classification research.

**Kaggle Link:**  
https://www.kaggle.com/datasets/smmohiuddinkhanshiam/ubi-fights

---

### 5. SCVD Dataset

**Description:**  
The Surveillance Camera Violence Detection (SCVD) dataset contains surveillance footage for violence recognition and public safety applications.

**Kaggle Link:**  
https://www.kaggle.com/datasets/smmohiuddinkhanshiam/scvd-dataset

---

### 6. VAD_Binary (Developed by Our Research Team)

**Description:**  
VAD_Binary is a binary violence anomaly detection dataset created to support research in violence recognition, anomaly detection, and surveillance video analytics.

**Kaggle Link:**  
https://www.kaggle.com/datasets/smmohiuddinkhanshiam/vad-binary
